# Huffman Messenger

Huffman Messenger is a web-based project that demonstrates Huffman Coding for text encoding and decoding.

## Features

- Enter a text message
- Generate character frequency
- Create and visualize the Huffman Tree
- Generate binary Huffman codes
- Encode the message into binary
- Decode the binary message
- Display the original message

## Technologies Used

- HTML
- CSS
- JavaScript
- SVG

## How It Works

The project follows this process:

Message → Character Frequency → Huffman Tree → Binary Code → Encoded Message → Decode → Original Message

Huffman Coding is a lossless data compression technique that uses different binary codes for different characters based on their frequency.
